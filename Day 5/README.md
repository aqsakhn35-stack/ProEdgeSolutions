# Day 5 - CSS Flexbox and CSS Grid

## Student Registration Portal Dashboard

### Objective

The objective of this task is to create a modern and responsive student dashboard using CSS Flexbox and CSS Grid.

### Work Completed

- Created a Dashboard Header with logo, title, and navigation menu.
- Added 4 Statistics Cards:
  - Total Students
  - Active Students
  - Departments
  - Courses
- Added Quick Action buttons:
  - Add Student
  - View Students
  - Departments
  - Reports
- Added 8 student profile cards.
- Each student card contains:
  - Student Image
  - Student Name
  - Department
  - Semester
  - View Profile Button

### CSS Flexbox

Flexbox is used for:

- Dashboard Header
- Navigation Bar
- Statistics Cards
- Quick Action Button Group

The following Flexbox properties are used:

- display: flex
- justify-content
- align-items
- flex-direction
- gap
- flex-wrap

### CSS Grid

CSS Grid is used for the Student Cards Section.

The following Grid properties are used:

- display: grid
- grid-template-columns
- grid-template-rows
- gap
- place-items

### Styling

The dashboard includes:

- Consistent colour palette
- Professional typography
- Card shadows
- Rounded corners
- Hover effects
- Proper spacing
- Clean alignment

### Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
