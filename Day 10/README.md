Student Management System

Day 10 – JavaScript Arrays & Objects

Project Description

The Student Management System is a web-based application developed using HTML, CSS, and JavaScript.

The application allows users to add student records, store student information using JavaScript arrays and objects, display records dynamically in a table, delete student records, and automatically update the total student count.

Features

- Student registration form
- Add new student records
- Display student records dynamically in a table
- Delete student records
- Automatically update total student count
- Prevent empty fields
- Prevent duplicate Student IDs
- Validate email format
- Display validation error messages

Student Information

Each student record contains:

- Student Name
- Student ID
- Department
- Semester
- Email Address
- Contact Number

Technologies Used

- HTML5
- CSS3
- JavaScript

JavaScript Concepts Used

- Arrays
- Objects
- Array Methods
- Loops
- Functions
- DOM Manipulation
- Event Handling
- Form Validation
