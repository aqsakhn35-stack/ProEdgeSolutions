# Simple Calculator

## Description
A simple calculator application built using HTML, CSS, and JavaScript.

## ES6+ Refactoring
- Used `const` and `let` instead of `var`
- Used arrow functions
- Used template literals
- Used modern JavaScript event handling
- Improved code readability and structure

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+)
