# Student Grade Calculator

## Project Description

This project is a Student Grade Calculator developed using HTML, CSS, and JavaScript. It allows users to enter student marks and calculates the total marks, percentage, and grade.

The project includes input validation and error handling to ensure that valid marks are entered.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Features

- Enter student marks
- Calculate total marks
- Calculate percentage
- Display grade
- Input validation
- Validation error handling
- User-friendly interface
- ES6 JavaScript features
- Refactored and organized code

## Project Structure

- `index.html` – Student Grade Calculator structure
- `style.css` – Styling and layout
- `script.js` – Calculation and validation functionality
- `screenshots/` – Project screenshots
- `README.md` – Project documentation
